# Agent Note: 记住每个模型的推理强度选择

Status: implemented

[English](2026-08-26-remember-per-model-reasoning-effort.md) | 中文

## 问题

composer 与 `/model` 弹窗都把模型切换组合成 `{ provider, model }`，因此适配器默认推理强度总会被重新应用。使用三方推理模型的用户每次切换模型后都要手动重选思考深度，刷新后选择也会丢失。

## 决策

- 增加按 `provider/model` 键控的浏览器本地偏好映射，保存最后一次显式选择的推理强度（`localStorage` 键 `dsh.modelSelection.efforts`）；非浏览器环境或存储失败时静默禁用。
- composer 与 `/model` 选择入口在构造模型切换时都查询该映射：只有目标模型仍公布该档位时才应用记忆值，否则应用模型默认值。
- 选择“提供方默认”一行会清除该路由的记忆值。被拒绝的选择不会持久化。

## 备选方案

- **在用户设置中做 Host 侧持久化**——本迭代否决：推理强度是浏览器内的 UI 偏好，不是持久的对话设置；localStorage 让改动完全留在客户端包内。
- **把当前档位原样带到不同模型**——否决：三方模型公布的档位词汇不同；携带不支持的档位会在网络 I/O 前让请求失败。

## 后果

- 从三方模型切走再切回时，无需手动重选即可恢复上次选择的思考深度。
- 记忆只按浏览器 profile 保存，不跨设备同步；该限制已写入包 README。
